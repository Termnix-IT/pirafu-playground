# Pirafu2411 Playground 第4次 制作報告

第4次では、Webの試作にBlenderの部品を足していく進め方をやめ、Blenderの中だけで一枚の絵として成り立つ空間を先に作りました。Three.jsへの統合はしていません。既存の本番サイトと第3次試作（`prototypes/playground-3d`）にも手を入れていません。

レンダリング結果は `renders/` にあります。見比べるための一覧は次の4枚です。

- `renders/sheet_phase3_vs_4.jpg`：第3次と第4次を、昼・夕方・夜で並べたものです。
- `renders/sheet_times.jpg`：朝・昼・夕方・夜の4つの時間帯を並べたものです。
- `renders/sheet_scenery.jpg`：窓の外の空・雲・水面を並べたものです。
- `renders/sheet_terminals.jpg`：4台の端末を並べたものです。

## 何を作り直したか

### 建築：持ち上げた一枚の殻

第3次は、同じアーチを等間隔に並べてガラスを張った建物で、温室に見えていました。第4次は、**一枚の白い殻を3か所でつまみ上げた形**にしました。

- 正面は水平線に向かって大きく持ち上がり、ここだけガラスが入ります。開口の輪郭は左右で高さが違う、なだらかな山の形です。
- 右手は座ったときの目の高さだけ低く持ち上がり、床を下げたラウンジの横に細長い窓になります。
- 左手は人が通れる高さに持ち上がり、出入口になります。
- 頂部には楕円の天窓が開いています。縁から蔓が垂れ、真下の床には空を映す浅い水盤があります。

殻が地面に降りている所では、床がそのまま立ち上がってベンチになり、殻につながります。床・壁・天井の境目がなく、柱も梁もありません。同じ部材の繰り返しは、正面のガラスを支える細い方立だけです。方立には横桟を入れず、水平線を横切るものをなくしました。

ベンチの背には光の線を仕込んであり、夕方から夜にかけて殻の内側を下から照らします。

### 光：Cyclesの間接光

第3次は直射光と環境光だけで、影が硬く、明暗が人工的でした。第4次はCyclesで光の跳ね返りを計算しています。殻の内側は、開口から入った光が床と壁で何度も跳ね返って、なだらかな階調になります。

| 時間帯 | 狙い | 光の作り方 |
|---|---|---|
| 朝 | 澄んだ透明感 | 低い太陽が左前から差します。 |
| 昼 | 澄んだ明るさ | 太陽は左前の高い位置にあり、方立の細い影が床に落ちます。照明はすべて消灯しています。 |
| 夕方 | 情緒 | 太陽は正面の低い位置にあります。室内が金色に染まり、間接照明と吊り照明が灯り始めます。 |
| 夜 | 静謐 | 月明かりは弱く、間接照明・吊り照明・端末の画面が光だまりを作ります。 |

室内を正しい明るさで写すと窓の外が白く飛ぶので、カメラから見える空だけを少し暗くしています（照明としての空の強さは変えていません）。写真でいうハーフNDフィルターに当たる処理で、`look.py` の `SKY_SEEN` です。

### 色の方向：朝と昼は寒色寄り

最初のレンダリングは殻と床が暖かい白で、第3次やコンセプトアートと並べると青みが弱く見えました。そこで、昼の主構図で暖かい白の案と寒色寄りの案を見比べ、寒色寄りを選びました。殻と床の素材を冷たい白に変え（`scene.py`）、朝と昼は白の基準も寒色に寄せています（`look.py` の `wb`）。夕方と夜は白の基準を動かしていないので、低い太陽と照明の暖かい色がそのまま残ります。

端末のクローズアップは日陰の部分が多く、朝と昼に主構図と同じだけ寒色に寄せると、白いセラミックが青く見えます。そこで、朝と昼のクローズアップの4構図だけ、白の基準を暖色側へ少し戻しています（`look.py` の `wb_close`）。

### 素材

| 素材 | 使った所 | 光への反応 |
|---|---|---|
| 鉱物質の漆喰 | 殻 | つやはありません。細かい凹凸で光がやわらぎます。 |
| 磨きを抑えたテラゾー | 床 | 反射はぼけます。場所によってつやにむらがあります。 |
| 白いセラミック | 端末と作り付けの家具 | クリアコートがあり、輪郭に鋭いハイライトが乗ります。 |
| サテン仕上げのアルミ | 操作部、キーボードの台、案内プレート | 光を鈍く反射します。 |
| アルマイト | アクセントのキー、スティック、ダイヤルの輪 | 作品のサムネイルから取った色が乗った金属です。反射は鈍く、色のついたハイライトが出ます。 |
| 薄いシャンパン色のアルマイト | 方立、水盤の縁の象嵌 | 反射は鈍く、暖かい色のハイライトが出ます。青い景色に対する暖色として使っています。 |
| 透明ガラス | 正面の窓、ガラスの覆い | 浅い角度で見たときだけ周囲が映り込みます。 |
| 乳白ガラス | 吊り照明、床の球 | 中の光をやわらかく通します。 |
| ボイル | カーテン | 光を通し、布の中で光がにじみます。 |
| ブークレとウール | 座面、クッション、毛布、スピーカー | つやはありません。近づくと織りの凹凸が見えます。 |

床は、第3次の鏡のような反射をやめました。屋内の床は反射をぼかし、水盤は鏡のように反射させ、屋外の水面は波のある反射にして、3つが別の物に見えるようにしています。

### 端末と家具：ひとつながりのセラミック

第3次は「机の上にモニターを置いた」構成でした。第4次は、**机・脚・画面の筐体をひとつながりの白いセラミック**にしています。単純な立体を重ねてから全体を融合し、角と継ぎ目を同じ丸みでなでる方法（`lib.py` の `soften`）で作りました。そこへ、画面のガラス、アルミの操作部、アルマイトの部品、布を、精密な別部品としてはめ込んでいます。

| 端末 | 造形 | 用途が伝わる要素 |
|---|---|---|
| GAME | くびれた脚、手前に傾いた操作盤、角の丸い4:3の画面を備えています。 | スティックと3つのボタン、丸椅子 |
| TOOL | 片側の脚から天板が翼のように伸び、奥の縁から横長の画面が立ち上がります。 | キーボード、ダイヤル、ペンタブレット、椅子 |
| EXPERIMENT | 立って使う柱の形で、縦長の楕円の画面と作業用の棚を備えています。 | ガラスの覆いの中で光る小さな芽 |
| MEDIA | 縦溝のある弓なりの壁に横長の画面があり、足元にはウールのスピーカーを備えています。 | 向かいに置いた寝椅子 |

カテゴリー名は、浮かぶUIラベルを使わず、筐体への刻印と、台の上の低い案内プレートで示しています。

### 窓の外

窓の外は、空・雲・水面の3種類の景色を切り替えられます。

- **空**：Blenderの大気散乱の空に、ボリュームで作った積雲を置きました。近くに背の高い雲、遠くに小さな雲を置いて、距離感を出しています。
- **雲**：建物の下に雲の層を敷き、水平線まで続けています。ところどころ雲が塔のように立ち上がります。
- **水面**：背の高い雲をなくし、水平線近くに低い雲だけを残しました。波を少し強めています。

### 人の痕跡

TOOLの机には飲みかけのカップ、開いたノート、ペンを置き、GAMEの椅子にはヘッドホンを置いています。ラウンジのテーブルには伏せた本とカップを、座面には畳んだ毛布を置いています。左のベンチにはクッションと数冊の本を置き、カーテンは左側だけ半分引いてあります。

## 自己レビュー

依頼にあった観点ごとに、できたことと足りないことを書きます。

- **建築そのものが美しいか**：開口の輪郭と、殻の内側の階調は狙いどおりです。一方、主構図では画面の上3分の1が無地の天井になり、天窓は別の構図でしか見えません。左の出入口も主構図にはほとんど写りません。
- **照明が人工的すぎないか**：昼と夕方は自然に見えます。夜は光だまりができましたが、暖色が強く、月明かりの青との対比はまだ弱いです。昼は、床の中央に太陽の光がはっきり落ちる状態を作れていません（方立の影は窓際にだけ出ます）。
- **素材ごとの違いが伝わるか**：クローズアップでは、セラミック・アルミ・布・ガラスの違いが分かります。引いた構図では、殻の漆喰と家具のセラミックがどちらも白く、つやの差だけで見分けることになります。
- **奥行きがあるか**：手前の端末、水盤、奥の端末、ガラス、海、雲の順に層ができています。
- **プリミティブを並べただけに見えないか**：TOOLとラウンジは一体の造形に見えます。GAMEの脚と椅子はまだ単純な回転体です。MEDIAの縦溝は、弓なりの壁を細かい板で作った結果を活かしたもので、最初から意図して設計した形ではありません。
- **工業製品として成立しているか**：TOOLがいちばん近づきました。どの端末も、継ぎ目・端子・脚のゴム・通気口のような細部がありません。近くで見ると「模型」に見えかねません。
- **窓の外に魅力があるか**：昼の積雲は立体的に出ました。朝・昼・夕方・夜で雲の配置は同じで、変わるのは光だけです。夜の星は細かくしすぎて、ほとんど見えません。雲海は上面が平らで単調です。水面は静かですが、光のきらめきは主構図には入っていません。遠くの島や鳥のような、目が留まる要素もありません。
- **コンセプトアートに近い情緒があるか**：静けさと、空・雲・水の広がりはコンセプトアートに近づきました。朝と昼を寒色寄りにしたので、青みも近づいています。ただ、コンセプトアートは光の反射と植物がもっと多く、きらめきがあります。第4次は白と余白が多く、落ち着きすぎています。植物、ガラスの小物、床に映る色は足せます。

## 残っている課題

1. 上の自己レビューで足りないと書いた点（無地の天井、夜の色の対比、昼の光だまり、端末の細部、雲海の単調さ、きらめき）を改善する必要があります。
2. 画面に映しているのは作品のサムネイルをそのまま貼ったものです。端末ごとのUI（`端末UIのデザイン案.md`）はまだ作っていません。
3. カーテン・植物・水面は静止しています。動きはWeb側で付ける前提です。
4. Web用のメッシュ、ライトマップ、空の画像はまだ作っていません（`Web移植の方針.md`）。
5. 主構図の昼だけを1920×1080で、ほかは1280×720でレンダリングしました。細部にノイズ除去の跡が残っているところがあります。
6. MEDIAのクローズアップは、手前の寝椅子が画面の下半分をふさいでいます。カメラの位置を直す必要があります。

## 作り直し方

Blender 5.2を使い、`prototypes/playground-cinematic/blender` から以下のコマンドを実行します。手順3にはNode.jsが必要です。

```powershell
# 1. シーンを生成して build/playground_p4.blend に保存（約1分）
& "C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" --background --factory-startup --python scene.py

# 2. レンダリング（renders/ に出力）
& "C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" --background --factory-startup --python render.py -- --views main --time noon --scenery sky --size 1920x1080 --samples 200

# 3. 比較用の一覧画像
node ..\scripts\contact-sheets.mjs
```

`--views` には `main`・`wide`・`up`・`lounge`・`sofa`・`game`・`tool`・`experiment`・`media`、`--time` には `morning`・`noon`・`evening`・`night`、`--scenery` には `sky`・`cloud`・`water` を指定できます。

| ファイル | 内容 |
|---|---|
| `blender/lib.py` | 形を作る関数をまとめている。第3次のものに、融合して丸める `soften` などを足した |
| `blender/arch.py` | 殻、床、方立とガラス、間接照明、水盤を作る。形はすべて数式で決まる |
| `blender/furniture.py` | 4台の端末とラウンジを作る |
| `blender/details.py` | カーテン、植物、照明、人の痕跡を作る |
| `blender/look.py` | 空、太陽、時間帯、3つの景色を設定する |
| `blender/scene.py` | 素材を定義して全体を組み立て、.blendを保存する |
| `blender/render.py` | Cyclesでレンダリングする |
| `blender/stats.py` | 部位ごとのポリゴン数を集計して表示する |
| `scripts/contact-sheets.mjs` | 比較用の一覧画像を作る |

.blendとレンダリング画像は、スクリプトから作り直せるので `.gitignore` で管理対象から外しています。
